AI hallucination refers to instances where a large language model generates text that is factually incorrect, fabricated, or not grounded in its training data or provided context, while presenting it with confidence. Retrieval-Augmented Generation (RAG) is a technique that mitigates hallucination by retrieving relevant documents from an external knowledge source and providing them to the model as context before generation. RAG systems typically consist of a retriever, which finds relevant passages using vector similarity search, and a generator, which produces a response conditioned on the retrieved passages. Common evaluation metrics for hallucination detection include faithfulness (does the output match the source), factual consistency, and entailment scoring using natural language inference models. Real-time hallucination detection systems verify claims incrementally as text is generated, rather than waiting for the full output, in order to provide low-latency feedback to users.
