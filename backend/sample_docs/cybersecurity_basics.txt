Multi-factor authentication improves account security by requiring two or more independent types of evidence, such as a password and a security key. Phishing is a social-engineering technique that attempts to trick people into revealing information or opening a malicious link. Software updates often include security fixes, so delaying updates can leave known vulnerabilities unpatched. A strong password should be long, unique to one account, and difficult to guess. Backups help organizations recover from accidental deletion, hardware failure, and ransomware, especially when at least one backup is kept separate from the main network.
